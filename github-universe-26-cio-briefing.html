ENTERPRISE POLICY
支持强制开启防降级
模式 A · 云端托管隔离

Cloud Sandboxes

适用：移动办公应急、跨部门常规业务研发
  • 物理隔离本机：在 GitHub 独立云端环境中检出代码与运行测试，零本地环境污染。
  • 休眠快照不丢进度：突破传统 1 小时超时限制，空闲自动保存状态，随时秒级唤醒。
  • 只读安全探查：对仅有阅读权限的代码仓也可零配置启动故障排查。
成熟度：正式商用 GA 计费：共用 Actions 美元池
模式 B · 企业内网专属

私有 Actions 运行器

适用：金融/政企核心系统、需连内网数据库
  • 代码不出内网边界：直接调度企业自建机房或专有云内的自托管 Runner 执行任务。
  • 复用既有安全审计：完全继承企业现有防火墙、堡垒机与制品库访问策略。
  • 多仓协同不受限：可在同一受控环境中拉取内部私有依赖包完成集成编译。
成熟度：正式商用 GA 计费：复用企业自有机器
模式 C · 员工终端原生围栏（重点新增）

Local Sandboxing 本机沙箱

适用：日常本地编码，防范越界删改与密钥泄露
  • 轻量化系统级围栏：免装虚拟机或容器，直接限制智能体仅能读写当前项目目录。
  • 真实密钥不进沙箱：沙箱内仅见占位假凭据，仅访问授信域名时由本地代理自动注入。
  • MDM 强控防裸跑：安全团队可统一下发策略并开启“不可用即阻断”，杜绝私自关闭。
成熟度：正式商用 GA 计费：$0 席位免费内含
CISO 协同建议：将“本机沙箱强制策略”纳入终端安全基线，零硬件采购即可消除本地 Agent 越权风险 覆盖 macOS · Linux · Windows 11
