Copilot Fusion：按档位自动路由与多模型审校

开发者声明 Effort 投入预算，系统逐轮动态匹配 Single、Cascade 或 Critique 执行模式。

AA INDEX v2.0 · FUSION MAX / CLI
60 · 官方称耗时约 -40%
PATTERN 01 · SINGLE 单模型最优直出

零审查开销极速响应

Router → 最优单模型 → 直接输出

当任务清晰、无需多模型复核时直接匹配最契合模型，是 Fusion Standard 与行内 Fast 档位的核心路径。

PATTERN 02 · CASCADE 先快后强级联升级

轻量起草 + Judge 质检升级

初稿 → Judge 检验 → 按需升级强模型

高性价比模型先打草稿，Judge 模型判定通过则立刻返回；遇到卡壳则自动升级强推理模型接力完成。

PATTERN 03 · CRITIQUE 异构模型并行挑刺

多模型并行审查 + 聚合修订

主模型初稿 → 多 Critic 并行挑刺 → 定稿

多个不同模型并行独立挑刺，汇总反馈后由原主模型修订，消除单模型盲区（中间草稿自动隐藏）。

档位与模式关系
Fast：VS Code 行内极速 · Standard：单模型均衡（全计划） · High：按需 Cascade / Critique · Max：重度 Critique 深度推理
关系本质：Effort 定预算偏好，Router 定当次模式
